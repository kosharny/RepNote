# Готовые планы и рисованные иллюстрации

Дата: 30 октября 2026 года.

## Поведение

Добавлена вкладка «Планы» с тремя программами для тренажёрного зала:

| План | Тренировки | Расписание по умолчанию |
| --- | --- | --- |
| Full Body | A, B, C | Пн / Ср / Пт |
| Верх / низ | Верх A, Низ A, Верх B, Низ B | Пн / Вт / Чт / Пт |
| Push / Pull / Legs | Push, Pull, Legs | Пн / Ср / Пт |

Перед добавлением можно изменить дни недели. Все тренировки выбранной программы добавляются одной транзакцией, появляются на главном экране вместе, в порядке расписания, с названием программы и днём недели. Это повторяемое недельное расписание без календарных дат и уведомлений.

Каждая программа содержит упражнения, начальные подходы и ориентир по повторениям. Вес пользователь вводит самостоятельно. Скопированные тренировки доступны обычному редактору. Заметка с повторениями видна также при вводе результатов упражнения.

Повторное добавление блокируется, пока в библиотеке остаётся хотя бы одна тренировка программы. В подробностях показаны фактические дни уже добавленной программы и отсутствующие после удаления тренировки. После удаления всех её тренировок либо полного сброса программу можно добавить снова.

Каталог и элементы интерфейса переведены на английский, русский, украинский и польский. Названия и заметки копируются в пользовательскую библиотеку на выбранном при добавлении языке; последующая смена языка сохраняет эти записи. Общие упражнения программ переиспользуются по постоянному ключу. Совпавшие пользовательские упражнения сохраняют свои названия и заметки.

Экран загрузки отображается минимум 1,2 секунды с момента появления Compose-контента и дольше, если данные ещё загружаются. Задержка не блокирует главный поток и не повторяется при обычном пересоздании Activity с сохранённым состоянием. Ошибка загрузки доступна сразу.

## Архитектура и данные

Сохранены существующие Kotlin / Compose / Material 3, Navigation 3 и ручная DI. Новый поток имеет отдельную `WorkoutPlansViewModel`, неизменяемое состояние, Route с lifecycle-сбором и Screen с callbacks. Выбор дней восстанавливается через SavedStateHandle. Каталог содержит определения ресурсов; импорт выполняется repository и Room DAO.

Room обновлён с версии 5 до 6 через AutoMigration: добавлены источник программы, день недели, позиция тренировки и ключ встроенного упражнения. Старые схемы сохранены, зависимости не обновлялись. Назначение дня не меняет историю и существующие черновики.

Единый стиль — фактурная гуашь, тёмно-зелёный рисованный контур, мята, шалфей, светлые блики и небольшие охристые акценты. Изображения проверены в светлой и тёмной темах. ## Фактическая проверка

Финальная команда `JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-21.jdk/Contents/Home ./gradlew :app:assembleDebug :app:lintDebug` выполнена успешно. Android Lint: 0 ошибок, 16 предупреждений (обновления версий, прежние неиспользуемые цвета и API-атрибут localeConfig). Правила Lint не ослаблялись. Итоговый APK имеет applicationId `com.example.repnote`. Автотесты не добавлялись, не изменялись и не запускались.

Ручная проверка выполнялась на существующем эмуляторе API 37 в отдельном приложении `com.example.repnote.plansreview`, без сброса данных основного приложения:

- Проверена реальная миграция базы версии 5 с существующими тренировкой, упражнением, заметкой, историческим результатом 40 × 8 и черновиком. После запуска версия базы — 6, записи и черновик сохранены, `foreign_key_check` пуст.
- Через интерфейс добавлены все три программы: 3 + 4 + 3 тренировки. Для Full Body изменён день с пятницы на субботу; в базе записаны Пн / Ср / Сб и позиции 0 / 1 / 2. Остальные программы сохраняют своё расписание и порядок.
- После импорта: 10 новых тренировок, 23 разных встроенных упражнения, 53 связи с упражнениями; ошибок внешних ключей нет. Повторный импорт заблокирован, сохранённое расписание отображается в каталоге.
- Проверены русский интерфейс и тёмная тема, польский интерфейс, главный экран и подробности программы при шрифте 200%. Системный масштаб возвращён к 100%.
- Полный сброс проверочной копии удалил программы, историю и упражнения; последующий импорт Full Body на польском создал 3 тренировки и 15 упражнений. Польская заметка с повторениями видна на экране ввода подходов. Ошибок внешних ключей нет.
- Проверен холодный запуск с экраном загрузки. Общее время запуска зависит также от системного splash и загрузки процесса; 1,2 секунды — минимальная длительность именно экрана Compose.

Проверка ограничена эмулятором API 37. Физическое устройство, старые версии Android и планшет отдельно не проверялись.
