# RepNote — прошлый результат рядом с новым подходом

## Идея
Локальный дневник силовых тренировок для человека, который забывает рабочие веса
и ищет прошлые записи между подходами. Открывая упражнение, пользователь видит
последнюю завершенную тренировку этого упражнения и записывает новый результат.
Пример: прошлый раз «60 кг × 8», сейчас пользователь сам выбирает «62,5 кг × 8».
Приложение фиксирует факты; оно не назначает безопасную нагрузку и не оценивает технику.

## Первая законченная версия
- Создать и редактировать шаблон тренировки из своих упражнений.
- Начать тренировку по шаблону; записать вес, повторения и выполнение подходов.
- Увидеть прошлые подходы и дату предыдущей завершенной тренировки упражнения.
- Завершить тренировку и открыть ее в истории; сохранить черновик незавершенной.
- Темная, светлая и системная темы; данные локально, без регистрации.
- Ручное добавление упражнения: название и необязательная заметка.

Дополнительные учебные этапы после MVP: фильтры истории, график одного упражнения,
таймер отдыха, экспорт. Сеть, подписки, ИИ, Health Connect и фоновые сервисы
не входят в первую версию. Retrofit можно освоить отдельным расширением позже.

## Сценарий
Тренировки → «Верх тела» → «Начать» → «Жим лежа» → ввести подходы →
перейти к следующему упражнению → «Завершить» → сохранить → История → детали.
При активном черновике главный экран предлагает «Продолжить».

## Экраны и состояния
| Экран | Содержимое | Действия и состояния |
|---|---|---|
| Тренировки | Шаблоны, последний результат, активный черновик | Создать, открыть, продолжить; пустой список с ясным CTA |
| Редактор шаблона | Название, упражнения, количество подходов | Добавить/удалить упражнение; ошибки пустого имени |
| Выполнение | Название упражнения, предыдущие подходы, ввод текущих | Отметить подход, переключить упражнение, сохранить черновик |
| Завершение | Итог и необязательная заметка | Сохранить; запрет повтора сохранения; сообщение об ошибке |
| История | Тренировки по датам | Открыть запись; пустое состояние |
| Детали истории | Упражнения и фактические подходы | Просмотр; удаление с подтверждением |
| Настройки | Тема и краткое описание | System / Light / Dark; кг в первой версии |

Состояния данных: загрузка, содержимое, пусто, ошибка и повтор. Для черновика:
Back возвращает на главный экран с сохранением; удаление черновика отдельно подтверждается.

## Правила данных
- Template, Exercise, Session, SessionExercise, SetEntry — концептуальные модели.
  Room-схему ученик проектирует после знакомства с данными и отношениями.
- Упражнение идентифицируется ID, а не названием. Переименование не рвет историю.
- Предыдущие значения берутся из последней завершенной сессии этого упражнения,
  исключая текущий черновик. Без истории показывается «Первый раз».
- В истории сохраняется снимок названия и порядка упражнений: редактирование
  шаблона не изменяет уже завершенные записи. Дата хранится с учетом часового пояса.
- Повторения — положительное целое; вес — неотрицательное число, 0 означает без
  дополнительного веса. Обрабатывать точку/запятую, пустой и некорректный ввод.
- На MVP окончание возможно после хотя бы одного выполненного подхода.
  Невыполненные строки не учитываются в итогах. Сохранение завершения атомарно.
- Расчет объема: сумма вес × повторения выполненных подходов; эта метрика
  не сравнивает разные упражнения и не оценивает качество тренировки.
- Черновик должен переживать перезапуск процесса. ViewModel сам по себе этого
  не гарантирует: черновик сохраняется в постоянном хранилище на позднем этапе.

## Дизайн
Образ: спокойный спортивный блокнот. Теплый светлый фон, глубокие зеленые
акценты, выразительная типографика, удобные поля и большая кнопка действия.
Вместо декоративных графиков — полезные прошлые значения рядом с вводом.
Три макета приложены: список тренировок, запись подходов, история.

| Роль | Светлая тема | Темная тема |
|---|---|---|
| primary | #365F48 | #A0D0AF |
| onPrimary | #FFFFFF | #093820 |
| primaryContainer | #BCECC8 | #214F35 |
| onPrimaryContainer | #0B2112 | #BCECC8 |
| surface | #F8FAF5 | #111510 |
| onSurface | #191D18 | #E1E5DC |
| surfaceContainer | #EBEFE5 | #1D211B |
| onSurfaceVariant | #43483F | #C3C8BE |
| outline | #74796F | #8D9388 |

Это стартовые брендовые роли, не полный ColorScheme. Полную палитру и контраст
проверяем при реализации. Дополнительно можно включить dynamic color Android 12+.
Оно меняет палитру: сравнение с брендовым макетом делается при его отключении.

- Material 3 компоненты: Scaffold, TopAppBar, NavigationBar, Card,
  FilledButton, OutlinedTextField, Checkbox, FAB и Snackbar по назначению.
- Основные направления внизу: Тренировки, История, Настройки. Выполнение и детали
  открываются глубже и используют Back; нижняя навигация там скрыта.
- Базовая сетка 8 dp; боковые отступы 20 dp; промежутки 8/16/24 dp.
  Это выбранные токены проекта, а не обязательные значения Android.
- Типографика: headlineMedium 28 sp, titleLarge 22 sp, bodyLarge 16 sp,
  bodyMedium 14 sp, labelLarge 14 sp. Текст масштабируется с системным шрифтом.
- Зоны касания минимум 48 × 48 dp. Маленькие иконки находятся внутри такой зоны.
- Системные панели, жестовая навигация, IME и edge-to-edge учитываются через insets.
- TalkBack: подписи действий, порядок чтения, обозначение выполненного подхода.
  Нельзя передавать статус одним цветом. Декоративным иконкам не нужна озвучка.
- На телефоне один столбец; на широком окне список и детали могут быть рядом,
  NavigationRail заменяет нижнюю панель. Ориентируемся на окно, не модель устройства.
- Проверки: крупный шрифт 200%, темная тема, клавиатура, маленький экран, планшет,
  поворот, системный Back, восстановление черновика после закрытия процесса.

## Готовность MVP
Пользователь без входа создает шаблон, записывает тренировку, закрывает приложение,
снова открывает историю и видит сохраненные подходы. Следующая тренировка показывает
предыдущие значения. Некорректные поля не сохраняются, данные не дублируются.
