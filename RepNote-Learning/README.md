# RepNote — Android-проект с преподавателем Codex

Это стартовая концепция и учебный комплект, а не готовый Android-проект.
Приложение реализует ученик. Код приложения в комплект не входит.
Название рабочее; уникальность бренда и доступность в Google Play не проверялись.

## Быстрый старт
1. Создай в Android Studio проект Empty Activity с Kotlin и Jetpack Compose.
   Используй конфигурацию совместимых версий, которую создает установленная Studio.
   Запусти шаблон и убедись, что он работает до подключения учителя.
2. Скопируй AGENTS.md в корень Android-проекта рядом с settings.gradle.kts.
   Остальные Markdown-файлы тоже можно положить в корень, а макеты — в docs/design.
   Не перезаписывай существующий AGENTS.md: объедини инструкции вручную.
3. Открой эту же папку в локальном клиенте Codex. Для доступа к свежим файлам нужен
   локальный проект; отдельная загрузка одного промпта не подключает исходники.
4. Выбери доступ только на чтение (Read Only), если клиент его предлагает.
   Проверь фактические разрешения новой сессии. Plan/планирование и текстовая
   просьба «не меняй код» сами по себе не создают запрет записи.
5. Для проверяемого запуска через установленный Codex CLI открой терминал в корне
   проекта и выполни:

```bash
codex --sandbox read-only --ask-for-approval never
```

`read-only` ограничивает запись модельными командами; `never` запрещает запросы
на расширение разрешений. Это не означает «разрешить все». Ограничение относится
к агенту: ты продолжаешь редактировать проект в Android Studio.
Внешние плагины/IDE-инструменты с правами записи требуют отдельных ограничений;
не подключай их к учебной сессии. Существующие hooks тоже проверь перед запуском.

6. Вставь содержимое START_PROMPT.md в чат. Учитель сначала прочитает правила,
   оценит уровень и даст одну задачу. Он не должен создавать приложение за тебя.
7. После своей реализации попроси: «Прочитай изменения и проверь задание.
   Ничего не меняй. Сначала дай замечания и подсказки».
8. Сборку, эмулятор, lint и тесты запускай самостоятельно. Учитель разбирает вывод.
   Для нового чата сохрани запись в LEARNING_LOG.md и начни с чтения журнала.

Настройки твоего локального Codex здесь не изменялись. Названия пунктов интерфейса
могут зависеть от версии клиента. Если Read Only недоступен, используй CLI;
один AGENTS.md не следует считать технической гарантией отсутствия изменений.

## Файлы
- PROJECT_BRIEF.md — идея, функциональность, правила данных и дизайн.
- LEARNING_PLAN.md — этапы и критерии приемки.
- AGENTS.md — постоянные инструкции преподавателю.
- START_PROMPT.md — сообщение для первой сессии.
- LEARNING_LOG.md — журнал, который заполняешь ты.
- RepNote-design.svg / .png — три точных концептуальных макета.
